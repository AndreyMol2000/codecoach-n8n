# CodeCoach — n8n и Qwen3

Учебный наставник по JavaScript: пользователь задаёт вопрос в отдельном веб-чате, а workflow n8n проверяет данные, готовит учебный контекст и обращается к локальной языковой модели Qwen3. Ответ возвращается в чат вместе с идентификатором запроса и статистикой токенов.

Автор: Молчанов Андрей Владимирович. Проект по дисциплине «Стартап-экосистемы».

**[Пошаговая инструкция по запуску](START.md)** — запуск на подготовленном компьютере, установка с GitHub, настройка n8n и решение частых ошибок.

## Что работает

- Workflow из 13 функциональных нод с внешним POST-триггером.
- Настоящие вызовы Qwen3-1.7B Q8_0 через llama.cpp, без API-ключей.
- Четыре уровня помощи, проверка ввода, безопасный разбор числовых примеров.
- Ответы и ошибки доходят до пользователя через веб-чат.

Компактная модель может ошибаться. Каждый запрос независим, пользовательский JavaScript не исполняется.

## Запуск на Windows x64

Нужен Node.js 22–24. Первая установка требует интернета и скачивает веса модели размером около 1,83 ГБ, llama.cpp и зависимости n8n.

```powershell
cd codecoach-n8n
.\scripts\setup.ps1 -RuntimeRoot "$env:USERPROFILE\Documents\Codex\work\n8n-agent-runtime"
.\scripts\start.ps1
```

В новом экземпляре n8n создайте локального владельца, импортируйте `codecoach-workflow.json` через редактор и опубликуйте workflow, чтобы включить production webhook.

- Веб-чат: http://127.0.0.1:3010
- Редактор n8n: http://127.0.0.1:5678
- Модель: http://127.0.0.1:8081

Для повторного запуска на подготовленном компьютере выполните `.\scripts\start.ps1` из папки `codecoach-n8n`.

Подробности установки, структура нод и ограничения: [README проекта](codecoach-n8n/README.md).

## Проверка

```powershell
cd codecoach-n8n
node --test
```

Пять тестов проверяют обработку ввода, передачу вопроса модели, ошибки провайдера, числовые примеры и метаданные ответа. Для проверки полного сценария задайте вопрос в веб-чате и откройте соответствующее выполнение в n8n.

Локальные настройки, база n8n, пароли, журналы и веса модели исключены из Git. После клонирования они создаются локально.
